## Accessing the Educator Toolbox

The Educator Toolbox is accessed via a special in-game item that appears automatically in your inventory.

**How to open it:**
1. Find the **Educator Toolbox** item in your hotbar (bottom row of your inventory)
2. Right-click (or interact) with the item
3. The main menu opens with all classroom management tools

![Educator Toolbox item](images/toolbox-item.png)

!!! tip
    **Quick Access:** Keep the Educator Toolbox in slot 1 of your hotbar. Press the `1` key anytime to quickly select it, then right-click to open the menu.


### Teacher Access

!!! note
    **Automatic Setup:**
    - ✅ All teachers automatically receive the Educator Toolbox when they join the world
    - ✅ The toolbox cannot be removed from teacher inventories
    - ✅ If somehow lost, it can be recovered from the Creative Mode inventory (search for "Educator Toolbox")
    - ✅ Only teachers have access to the Educator Toolbox - students cannot see or use this item

## Tips for Using the Educator Toolbox

### Getting Started

💡 **Don't try to learn everything at once** - Start with [Essential Tools](Essential-Tools.md) (Teleport, Focus Mode, Manage Health, Gamemode, Set Time to Day)

💡 **Practice in an empty world first** - Try out tools before using them with students

💡 **Read the "When to use it" sections** - Learn which tool fits which classroom situation

### During Class

💡 **Keep the toolbox in your hotbar** - Put it in slot 1 for quick access (press 1 key)

💡 **Combine tools for powerful workflows** - Example: Use Focus Mode to explain an activity, then use Timer to track time, then Teleport to gather everyone at the end

💡 **Use Teams to save time** - Organize students into teams once, then target whole teams with other tools

### Common Mistakes to Avoid

❌ **Don't use Focus Mode too frequently** - Students get fatigued if their screens are constantly dimmed

❌ **Don't forget to unlock players** - If you lock students to an area, remember to remove the lock when done

❌ **Don't rely only on chat** - Chat messages scroll away; use Boss Bar or Focus Mode for important info

❌ **Don't set up timers without testing** - Make sure you know how to pause/edit/delete timers before using in class

## Troubleshooting

**Problem: I don't see the Educator Toolbox in my inventory**

Solutions:
- Check if you're in the Teachers team
- Leave and rejoin the world to trigger the toolbox appearing
- Open Creative inventory and search for "Educator Toolbox"

**Problem: A tool isn't working**

Solutions:
- Check the specific tool's requirements (some need 2+ players online)
- Verify Educator Tools pack is active in World Settings → Behavior Packs
- Read the tool's guide for common issues

**More help:** See [FAQ and Troubleshooting](FAQ-and-Troubleshooting.md)
