# 📋 Printable Quick Reference

## Opening the Educator Toolbox

1. Find the **Educator Toolbox** item in your hotbar (bottom row)
2. Right-click the item to open the menu

---

## Essential Tools (Start Here)

| Tool | How to Access | What It Does |
|------|---------------|--------------|
| **Custom Nicknames** | Toolbox → Custom Nicknames | Let students personalize display names |
| **Assignments** | Toolbox → Assignments | Create and collect student work |
| **Focus Mode** | Toolbox → Focus Mode | Dim screens and show a message for attention |
| **Lock Players** | Toolbox → Lock Players | Keep students in specific areas |
| **Letter Blocks** | Creative Inventory → Search "letter" | Build words and math problems in 3D |

## Classroom Control

## Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Toolbox not in inventory | Rejoin world, or get from Creative inventory |
| Nicknames not appearing | Check Settings → Nicknames Enabled is ON |
| Student can't set nickname | Enable "Prompt on Join" in Settings |
| Assignment not showing to students | Toggle "Notify Students" ON when creating |
| Can't view submissions | Check "Active Assignments" not "Completed" |
| Focus Mode won't enable | Check message field is filled, click "Disable Globally" to toggle |
| Lock Players not working | Verify radius is large enough, check Teleport to Center is ON |
| Can't find Letter Blocks | Open Creative inventory → Search tab → Type "letter" |

## Common Workflows

### First Day Setup
1. Enable Custom Nicknames (Settings → Prompt on Join ON, Require Approval ON)
2. Set time to Always Day
3. Let students choose nicknames when they join
4. Approve nickname requests

### Starting a Project
1. Create Assignment with project description
2. Use Focus Mode to explain the task
3. Lock Players to project area (optional)
4. Give students Letter Blocks if needed (Creative Inventory)

### During Class Activity
1. Use Timer for timed challenges
2. Use Focus Mode to give updates or instructions
3. Monitor Assignment submissions
4. Teleport to student locations to review work

### Ending Class
1. Use Focus Mode to announce end of class
2. Remind students to submit Assignments
3. Complete Assignment when deadline passes
4. Remove Player Locks if active

## Important Reminders

✅ **Teachers are immune** to Focus Mode, damage restrictions, and item limitations

✅ **Nicknames persist** across sessions - students don't need to re-enter them

✅ **Assignments collect data** - Use for formative assessment and progress tracking

✅ **Focus Mode freezes gameplay** - Students become invulnerable and can't interact

✅ **Lock Players has two modes** - Center (fixed location) or Player (follow mode)

✅ **Letter Blocks are unique** - Educational tool that doesn't exist in vanilla Minecraft

✅ **Test first** - Try new tools in an empty world before using with students

## Assignments Quick Guide

### Creating an Assignment
1. Toolbox → Assignments → Create
2. Name: Brief title (e.g., "Castle Build")
3. Description: Full instructions for students
4. Toggle "Notify Students" ON
5. Click Create

### Reviewing Submissions
1. Toolbox → Assignments → Active Assignments
2. Select the assignment
3. Click student name to view response
4. Click "Teleport to Location" to visit their work
5. When done: Complete Assignment

### Student View
- Students open their own Assignments menu
- See instructions and submit text responses
- Location is auto-captured when they submit

## Letter Blocks Quick Guide

### Getting Letter Blocks
1. Open inventory (E key) in Creative Mode
2. Search tab → Type "letter"
3. Drag blocks to hotbar

### Building Words
- Place blocks side-by-side to spell horizontally
- Stack blocks vertically for tall signs
- Leave empty spaces between words

### Classroom Ideas
- Spell vocabulary words
- Build math equations (2 + 3 = 5)
- Create labels and signs
- Display learning objectives
