## ❓ What are Extensions?

!!! note
    Extensions are separate add-on packs that work alongside the core Educator Tools pack. They provide additional content without bloating the base installation, allowing teachers to choose only the features they need.


**Key characteristics:**
- ✅ **Optional** - Install only what you want
- ✅ **Compatible** - Work seamlessly with the core pack
- ✅ **Independent** - Can be activated or removed without affecting core functionality
- ✅ **Expanding** - New extensions will be added over time

## ➕ Installing Extensions

!!! tip
    Extensions install the same way as the main Educator Tools pack - just download, double-click, and activate!


### Step 1: Download the Extension

1. Visit the [Releases page](https://github.com/ShapescapeMC/Educator-Tools/releases)
2. Find the extension you want (e.g., "More Letter Blocks v1.0")
3. Download the `.mcaddon` file

### Step 2: Import into Minecraft

1. Double-click the downloaded `.mcaddon` file
2. Minecraft Education launches and imports automatically
3. Sign in if prompted

### Step 3: Activate in Your World

1. Create a new world or edit an existing one
2. Navigate to **Behavior Packs** (and **Resource Packs** if needed)
3. Find the extension in the available packs list
4. Click the **"+"** button to activate it
5. Click **"Create"** or **"Save"**

**✅ Verification:** Join the world and verify the extension's content is available (e.g., search for new letter blocks in Creative inventory).

## ⚙️ Managing Extensions

### 🔧 Do I need the core pack?

!!! info
    **Yes!** Extensions require the core Educator Tools pack to be installed and activated. Always install the main pack first, then add extensions.


**Installation order:**
1. Install and activate **Educator Tools** (core pack)
2. Install and activate **Extension(s)** of your choice

### 🎯 Can I use multiple extensions together?

**Yes!** Extensions are designed to work together. You can activate as many as you want without conflicts.

### ❌ Can I remove an extension later?

**Yes!** Extensions can be deactivated or removed from your world at any time. Removing an extension won't affect the core pack or other extensions.

**To remove:**
1. Edit your world settings
2. Go to Behavior Packs (or Resource Packs)
3. Click the **"-"** button next to the extension
4. Save your changes

!!! warning
    Removing an extension will remove all content it added. For example, removing "More Letter Blocks" will delete all themed letter blocks from the world.

## 🔧 Troubleshooting Extensions

### Extension doesn't appear in pack list

**Solutions:**
- Make sure you downloaded the `.mcaddon` file (not source code)
- Restart Minecraft Education and try importing again
- Check Settings → Storage → Behavior Packs to confirm it imported

### Extension content doesn't appear in-game

**Solutions:**
- Verify the extension is **activated** in world settings (not just imported)
- Verify the **core Educator Tools pack** is also activated
- Leave and rejoin the world to trigger initialization
- Check the extension is compatible with your Minecraft Education version

### Extension causes errors or crashes

**Solutions:**
- Check the release notes for known issues
- Verify you're using compatible versions (core pack + extension)
- Remove the extension and report the issue on [GitHub](https://github.com/ShapescapeMC/Educator-Tools/issues)

### Extension interferes with core pack

**This shouldn't happen!** Extensions are designed to be independent. If you experience conflicts:
1. Remove all extensions
2. Test with core pack only
3. Add extensions back one at a time to identify the problem
4. Report the issue on [GitHub](https://github.com/ShapescapeMC/Educator-Tools/issues)
